# 한어울 그랑프리

Xbox 컨트롤러로 즐기는 2인 대전 3D 카트 레이싱. 브라우저에서 바로 돌아간다 —
빌드 도구도, 설치도 필요 없다.

## 실행

```bash
python run.py
```

웹서버를 띄우고 브라우저를 열어 준다. 손동작 조작을 쓸 때는 그것까지 함께 띄운다.
종료는 그 창에서 Ctrl+C. 윈도우라면 `실행.bat` 을 더블클릭해도 된다.

three.js는 CDN에서 받으므로 최초 실행에는 인터넷 연결이 필요하다.

### 조작 방식 전환

`run.py` 위쪽 한 줄로 바뀐다.

```python
HAND_STEERING = True    # 손동작 (배포용) — 게임 화면 모서리에 손 영상이 뜬다
HAND_STEERING = False   # 키보드 (테스트용) — P1: WASD / P2: 방향키, 카메라 칸 없음

DEBUG_WINDOW = True     # 인식 디버그 창(OpenCV)을 띄운다. 임계값을 숫자키로 조절할 수 있다
DEBUG_WINDOW = False    # 안 띄운다 — 배포할 때는 이쪽
```

`HAND_STEERING = True` 인데 카메라·패키지·모델이 준비되지 않았으면 이유를 알려주고
키보드로 넘어간다. 게임을 못 켜는 일은 없다.

서버만 따로 띄우고 싶으면 예전처럼 해도 된다.

```bash
python -m http.server 8000      # 또는: npx serve
```

## 조작

Xbox 컨트롤러를 연결하고 아무 버튼이나 누르면 인식된다. 패드가 없는 플레이어는 키보드로 넘어간다.

| | 게임패드 | P1 키보드 | P2 키보드 |
|---|---|---|---|
| 가속 / 브레이크 | RT / LT | W / S | ↑ / ↓ |
| 조향 | 왼쪽 스틱 | A · D | ← · → |
| 드리프트 | A 또는 RB | Space | 0 (메인) |
| 아이템 | X 또는 LB | 왼쪽 Shift | 오른쪽 Shift |
| 시작 / 일시정지 | Menu(Start) | Enter / Esc | |

## 특징

**동적 분할화면** — 두 카트가 26m 안쪽으로 붙으면 한 화면으로 합쳐지고, 34m 넘게 벌어지면 세로로
갈라진다. 히스테리시스를 둬서 경계에서 떨리지 않는다. 설정에서 자동/항상 분할/항상 한 화면 중
고를 수 있다.

**드리프트 미니터보** — 드리프트를 물고 버틴 시간에 따라 3단계로 차지되고, 놓으면 그만큼 부스트가
터진다.

**아이템 4종** — 버섯(가속)·등껍질(전방 발사)·바나나(후방 설치)·스타(무적). 뒤처진 쪽에 좋은
아이템이 나올 확률이 높다.

**부스터 패드** — 코스 곳곳의 발광 셰브론을 밟으면 부스트. 코너 탈출부에 깔려 있다.

**견인(러버밴딩)** — 선두와 30m 이상 벌어지면 최고속과 가속에 배율이 붙는다(130m에서 최대 1.25배).
접전 구간에서는 개입하지 않는다.

**맵 테마별 코스** — 각 맵이 형상·도로폭·색·안개·장식을 따로 갖는다. 타이틀 화면에서 ◀▶로 고른다.

## 구조

에셋 로딩은 전부 폴백을 갖는다. GLB/PNG/OGG 중 무엇이 실패해도 `null`로 흡수되고 절차 생성 메시와
WebAudio 합성음으로 되돌아가므로, 에셋 없이도 게임은 돌아간다.

```
index.html          importmap + 부팅
src/
  main.js           상태 머신(타이틀→카운트다운→레이스→결과), 조립, 순위, 견인, 부스터 판정
  tracks.js         맵 데이터 (순수 데이터: 제어점 · 테마 · 부스터 패드 위치)
  track.js          스플라인에서 트랙 지오메트리 생성 (도로 · 연석 · 벽 · 프롭 · 장식)
  kart.js           아케이드 물리, 드리프트, 랩 판정, 벽 슬라이드 충돌
  view.js           체이스캠 2개 + 동적 분할화면
  items.js          아이템 박스 · 발사체 · 설치물
  input.js          Gamepad API 폴링 + 키보드 폴백 + 리매핑
  hud.js            DOM 오버레이 HUD · 타이틀 · 결과 패널
  audio.js          샘플 재생 + WebAudio 합성 폴백
  assets.js         GLB/텍스처/오디오/폰트 로딩과 전처리
  settings.js       설정 모달 (localStorage 저장)
assets/             Kenney CC0 에셋 (CREDITS.md 참고)
design/             UI 시안 소스 (.dc.html) — 게임 실행에는 쓰이지 않는다
```

모듈 간 계약은 `CONTRACTS.md`, 에셋 배치 근거는 `ASSETS-PLAN.md`에 적어 두었다.
